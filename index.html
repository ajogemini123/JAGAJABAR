Satu tombol untuk tiga aksi darurat sekaligus: kirim lokasi GPS ke kontak terpercaya lewat WhatsApp/SMS, buka panggilan telepon otomatis, dan aktifkan rekaman audio. Bila tidak dinonaktifkan dalam 30 menit, alarm keras akan berbunyi dan hanya bisa dimatikan dengan passcode milikmu.

Cara kerja singkat: isi passcode dan kontak darurat sekali di awal (lihat panel di bawah). Saat kondisi mengancam, tekan tombol PANIC — sistem langsung mengirim sinyal darurat ke kontak yang kamu tentukan, tanpa perlu mengetik apa pun. Aplikasi ini berjalan sepenuhnya di perangkatmu; data passcode dan kontak tidak dikirim ke server mana pun.

Atur passcode dan kontak dulu di bawah sebelum darurat terjadi

1. Buat Passcode Alarm

Kode rahasia 4–8 digit yang wajib dimasukkan untuk menonaktifkan alarm. Hanya kamu yang boleh mengetahuinya.

Passcode wajib untuk mematikan alarm. Jangan beri tahu siapa pun, termasuk saat dipaksa dalam keadaan darurat. Disimpan dalam bentuk terenkripsi hanya di perangkat ini — tidak pernah dikirim ke server mana pun.

⏱ Durasi Sebelum Alarm Otomatis Aktif

Jika mode panic tidak dinonaktifkan dalam rentang waktu ini, alarm akan berbunyi otomatis dan notifikasi tambahan dikirim ke kontak darurat.

Dapat diganti kapan saja dan tersimpan otomatis di perangkat ini.

2. Kontak Darurat

Nomor WhatsApp yang akan menerima lokasi real-time dan notifikasi otomatis saat mode panic diaktifkan. Maksimal 5 kontak.

Format nomor bebas (08xx atau 628xx), sistem akan menyesuaikan otomatis.

Tentang JAGAJABAR

Aplikasi ini dirancang untuk mempercepat proses meminta bantuan saat situasi darurat, bukan sebagai pengganti layanan darurat resmi (112/110/113/119). Seluruh data passcode dan kontak tersimpan lokal di perangkat ini dan tidak pernah dikirim ke server pihak ketiga. Rekaman audio hanya merekam suara di sekitar perangkatmu sendiri.

Aplikasi berjalan selama halaman tetap terbuka di browser. Untuk hasil optimal, pastikan izin lokasi dan mikrofon telah diaktifkan sebelum situasi darurat terjadi.

⚠ ALARM AKTIF ⚠

Alarm ini hanya bisa dimatikan dengan passcode yang kamu buat sendiri.
